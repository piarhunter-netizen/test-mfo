# Сайт МКК «ЯсноЗайм»

Статический сайт микрокредитной компании: калькулятор займа, посадочные страницы под поисковые запросы, статьи, раскрытие информации по требованиям Банка России. Сборщик написан на Node.js без внешних зависимостей.

> **ЯсноЗайм** — условное название. Все реквизиты в `site.config.js` — заглушки (нули и `[квадратные скобки]`). Публиковать сайт МФО с вымышленными реквизитами нельзя: замените их данными своей компании.

## Быстрый старт

```bash
node build.js      # собрать сайт в dist/
node serve.js      # открыть http://localhost:8080
node build.js --strict   # сборка с остановкой при SEO- и юридических замечаниях
```

Нужен Node.js 18 или новее. Содержимое `dist/` можно загрузить на любой хостинг (nginx, Apache, S3, GitHub Pages). Если включить GitHub Pages (Settings → Pages → Source: GitHub Actions), workflow `.github/workflows/pages.yml` будет публиковать сайт сам.

## Структура

| Путь | Что внутри |
|---|---|
| `site.config.js` | реквизиты, контакты, параметры займа, адрес сайта, счётчики. **Начните отсюда** |
| `src/pages.js` | главная, посадочные страницы, условия, о компании, документы, контакты, вопросы |
| `src/blog.js` | статьи |
| `src/legal.js` | политика ПД, согласие на обработку ПД, политика cookie |
| `src/components.js` | калькулятор, блок ПСК, вопросы и ответы, таблица условий |
| `src/layout.js` | `<head>`, шапка, подвал, форма заявки, cookie-баннер |
| `assets/` | стили, скрипт, логотип |
| `static/` | файлы, которые копируются как есть (PDF-документы кладите в `static/docs/`) |
| `build.js` | сборка, sitemap.xml, robots.txt, og-картинка, проверки |

## Что сделано для SEO

- 27 страниц с уникальными title, description и одним h1: 6 посадочных под частые запросы («займ на карту», «через СБП», «онлайн», «до зарплаты», «с плохой КИ», «пенсионерам»), 7 статей, отдельные страницы условий, документов и вопросов.
- Разметка Schema.org в JSON-LD: `FinancialService`, `LoanOrCredit`, `FAQPage`, `HowTo`, `Article`, `BreadcrumbList`, `WebSite`.
- ЧПУ-адреса, canonical, Open Graph, `sitemap.xml`, `robots.txt` с `Clean-param` для Яндекса, HTML-карта сайта, хлебные крошки, перелинковка.
- Скорость: чистый HTML без фреймворков, один CSS и один JS (около 8 КБ), системные шрифты, нет блокирующих сторонних скриптов. Без JS страница тоже работает: контент виден, калькулятор показывает значения по умолчанию.
- Сборка проверяет длину и дубли title/description, количество h1 и запрещённые рекламные формулировки.

## Что сделано для соответствия закону

- **ПСК** в верхней части страниц с условиями, тем же шрифтом, что и ставка; в подвале — диапазон ПСК, ставка, сумма, срок (353-ФЗ).
- **Лимиты 2026 года**: ставка не выше 0,8 % в день, неустойка не выше 20 % годовых, переплата не выше 100 % суммы займа по договорам с 01.04.2026, запрет третьего займа с ПСК выше 200 % с 01.10.2026, самозапрет, период охлаждения.
- **Реклама финансовых услуг** (38-ФЗ, базовый стандарт с 01.07.2026): на каждой странице указано наименование МКК; нет обещаний «без отказа», «100 % одобрение», «без проверок»; выгодные условия не выделяются в ущерб остальным; дополнительные услуги не навязываются.
- **Раскрытие информации**: полное наименование, ИНН, ОГРН, номер в реестре МФО, СРО, адреса, ссылки на Банк России, интернет-приёмную ЦБ, финансового уполномоченного и базовые стандарты, порядок подачи обращений, раздел документов.
- **Персональные данные** (152-ФЗ): политика обработки, согласие на обработку оформлено **отдельным документом** (требование с 01.09.2025). Согласия в форме заявки не отмечены заранее. Согласия на БКИ, простую электронную подпись и рекламу — отдельные, согласие на рекламу необязательное.
- **Cookie**: Яндекс Метрика загружается только после нажатия «Принять все». Google Fonts, Google Analytics и другие сервисы, передающие данные за рубеж, не используются.
- **Закон о русском языке** (с 01.03.2026): весь текст для потребителей на русском, название бренда кириллицей.

## Перед запуском

1. Заполните `site.config.js`: реквизиты, номер в реестре ЦБ, СРО, адреса, телефоны, домен (`url`).
2. Положите PDF-документы в `static/docs/`, имена файлов указаны на странице «Документы». Пока файла нет, вместо ссылки выводится напоминание: битых ссылок не будет.
3. Укажите реквизиты для оплаты в `src/pages.js` (страница «Как погасить»).
4. Подключите обработчик заявок (`formEndpoint`): форма отправляет POST с JSON `{phone, amount, term, consents, consentedAt, page}`. Если обработчик вернёт `{redirect: "..."}`, пользователь перейдёт по этой ссылке. Анкету с паспортными данными держите в личном кабинете на серверах в РФ.
5. Отдайте юристу на проверку тексты в `src/legal.js` и формулировки условий: шаблоны составлены по нормам на ноябрь 2026 года, но обязанности конкретной компании зависят от её документов.
6. Положите свою картинку для соцсетей 1200×630 в `static/assets/og.png` (иначе сборщик генерирует простую с логотипом) и добавьте коды Вебмастера и Метрики в конфиг.
7. Подайте `sitemap.xml` в Яндекс Вебмастер и Google Search Console.
