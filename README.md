# Сайт МКК «ЯсноЗайм»

Одностраничный сайт микрокредитной компании: калькулятор со встроенной заявкой, вход в личный кабинет и обязательные документы. Сборщик написан на Node.js без внешних зависимостей.

> **ЯсноЗайм** — условное название. Все реквизиты в `site.config.js` — заглушки (нули и `[квадратные скобки]`). Публиковать сайт МФО с вымышленными реквизитами нельзя: замените их данными своей компании.

## Быстрый старт

```bash
node build.js      # собрать сайт в dist/
node serve.js      # открыть http://localhost:8080
```

Нужен Node.js 18 или новее. Содержимое `dist/` можно загрузить на любой хостинг. На GitHub Pages сайт публикуется сам через `.github/workflows/pages.yml`.

## Где работает

- **https://vietrp.com** — VPS 147.78.66.109 (Ubuntu 24.04): служба `mfo-site` (systemd, порт 127.0.0.1:8090), nginx с HTTPS от Let's Encrypt (продлевается автоматически), данные в `/var/lib/mfo-site/db.json`.
- Обновить сайт на сервере: выложить код в `/opt/mfo-site`, выполнить `node build.js` и `systemctl restart mfo-site`.
- GitHub Pages — только витрина без регистрации (формы в демо-режиме).

## Структура

| Путь | Что внутри |
|---|---|
| `site.config.js` | реквизиты, контакты, параметры займа, адреса серверов заявок и ЛК. **Начните отсюда** |
| `src/pages.js` | главная, условия, документы, вход в ЛК, 404 |
| `src/legal.js` | политика ПД, согласие на обработку ПД, политика cookie |
| `src/components.js` | калькулятор с заявкой, блок ПСК, вопросы и ответы |
| `src/layout.js` | `<head>`, шапка, подвал |
| `assets/` | стили, скрипт, логотип |

## Подключение серверной части

- **Заявка** (`formEndpoint`): POST JSON `{phone, amount, term, consents, consentedAt, page, utm, referrer}`. Ответ `{redirect}` переводит пользователя по ссылке.
- **Вход в ЛК** (`lkLoginEndpoint`): POST `{phone, password}` → `{redirect}` или `{error}`.
- **Восстановление пароля** (`lkResetEndpoint`): POST `{phone}` → отправка СМС, затем `{phone, code, password}` → `{ok}` или `{error}`.

Пока адреса не заданы, формы работают в демо-режиме. Серверы должны работать по HTTPS и хранить данные в России.

## Соответствие закону

- Ставка и ПСК указаны в карточке калькулятора в первом экране одним шрифтом; в подвале — сумма, срок, ставка, ПСК, неустойка и предельная переплата.
- В подвале: наименование, ИНН, ОГРН, номер в реестре МФО, СРО, адрес, ссылки на Банк России, интернет-приёмную, финансового уполномоченного и базовые стандарты.
- Согласия в форме — отдельные галочки без предварительных отметок; согласие на обработку ПД — отдельный документ.
- Яндекс Метрика и cookie-баннер включаются, только если задан `metrikaId`; Метрика грузится после согласия посетителя.

## Перед запуском

1. Заполните `site.config.js`: реквизиты, номер в реестре ЦБ, СРО, адреса, телефоны, домен (`url`).
2. Положите PDF-документы в `static/docs/` (имена — на странице «Документы»).
3. Подключите адреса серверов заявок и личного кабинета.
4. Отдайте юристу на проверку тексты в `src/legal.js` и формулировки условий.
